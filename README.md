# 健康检测手表

基于 STM32F407ZET6 + FreeRTOS 的健康检测智能手表，支持蓝牙通信、健康监测（心率/血氧/计步）、闹钟、低功耗管理与抬手唤醒等功能。

## 简介

本项目是一个以 STM32F407ZET6 为主控、FreeRTOS 为实时操作系统的健康检测智能手表项目。项目采用 **模块化 + 分层设计思想**，每个功能模块由独立的 `.c/.h` 文件实现，并由独立的 FreeRTOS 任务进行管理，最终通过一个主逻辑控制任务进行联调。分层与模块化的设计使得后期更换芯片或硬件平台时，只需替换底层驱动，上层业务逻辑无需改动。

## 功能特性

### 核心功能

- 蓝牙连接状态显示
- 手机设置日期、时间
- 计步显示
- 低功耗管理：20 秒内无任何操作自动熄屏，CPU 进入睡眠模式
- 抬手唤醒屏幕
- 手机设置闹钟时间
- 手机获取心率与血氧值
- 心率与血氧浓度图形化显示

### 扩展功能

- 可进入停止/待机模式
- 游戏功能
- 基于 GPRS 模块实现拨打/接听电话及短信功能
- 支持蓝牙或远程升级（OTA）

## 软件架构

### 分层设计

为了适应后期可能更换芯片硬件的情况，项目采用五层架构：

```text
┌─────────────────────────────────────────────┐
│              应用层 (APP Layer)              │
│   表盘显示 | 时间管理 | 闹钟 | 计步 | 游戏     │
├─────────────────────────────────────────────┤
│           中间件层 (Middleware Layer)        │
│   FreeRTOS | 蓝牙协议解析 | 数据处理 | OTA    │
├─────────────────────────────────────────────┤
│             BSP层 (BSP Layer)                │
│  显示驱动 | 触摸驱动 | 心率血氧传感器 |       │
│  ICM-20602 驱动 | 蓝牙驱动 | SIM800C 驱动    │
├─────────────────────────────────────────────┤
│           硬件抽象层 (HAL Layer)              │
│        STM32 标准库 / GPIO / SPI / I2C       │
│             / UART / RTC / TIM               │
├─────────────────────────────────────────────┤
│            硬件层 (Hardware Layer)           │
│  STM32F407ZET6 | P169H002-CTI | DX-BT24 |    │
│      ICM-20602 | SIM800C | 心率血氧传感器    │
└─────────────────────────────────────────────┘
```

### 任务划分

| 任务 | 说明 |
| ---- | ---- |
| 主控制任务 | 负责整体业务逻辑调度与任务间通信 |
| 显示任务 | 负责表盘、数据、图形界面的刷新 |
| 蓝牙任务 | 负责与手机的数据收发与协议解析 |
| 传感器任务 | 负责心率、血氧、加速度数据的采集与处理 |
| 低功耗任务 | 负责熄屏检测、睡眠管理与抬手唤醒中断处理 |

## 目录结构

```text
Health_Monitoring_Watch/
├── USER/               # Keil 工程文件（Template.uvprojx）+ 应用代码
│   ├── main.c          # 主函数：任务创建与调度
│   ├── stm32f4xx_it.c  # 中断服务函数
│   └── system_stm32f4xx.c # 系统时钟配置
├── HARDWARE/           # 硬件驱动模块
│   ├── LED/            # 指示灯
│   ├── DELAY/          # 延时（基于 FreeRTOS）
│   ├── SYS/            # 底层寄存器操作宏
│   ├── TIM3/           # 1ms 定时器（LVGL tick）
│   ├── ST7789/         # 显示屏驱动（P169H002-CTI，SPI）
│   ├── CST816/         # 触摸屏驱动（IIC）
│   ├── UART1/          # 调试串口
│   ├── DX24/           # 蓝牙模块驱动（DX-BT24，USART2）
│   ├── PROTOCOL/       # 通信协议解析
│   ├── RTC/            # 实时时钟（时间/闹钟）
│   └── BEEP/           # 蜂鸣器（闹钟响铃）
├── FreeRTOS/           # 中间件层：FreeRTOS 实时操作系统
├── LVGL/               # 中间件层：LVGL 图形库（含 examples/porting 移植层）
├── CORE/               # 启动文件与 Cortex-M4 内核头文件
└── FWLIB/              # STM32F4 标准外设库（StdPeriph）
```

> 当前为标准库直连结构，后续将按分层架构（APP / BSP / HAL 由开发者自行封装）逐步重构。新增传感器驱动（ICM-20602 抬手唤醒、心率血氧、SIM800C）时，在 `HARDWARE/` 下新建模块目录，并在 Keil 工程中添加对应源文件与头文件路径。

## 快速开始

### 开发环境

- Keil MDK
- STM32CubeMX
- J-Link 下载器

### 编译烧录

1. 使用 STM32CubeMX 生成工程（或直接打开已有工程）
2. 使用 Keil 编译工程
3. 通过 J-Link 烧录固件到开发板
4. 上电后通过串口/蓝牙查看运行日志
