# 健康监测智能手表

基于 STM32F407ZET6 + FreeRTOS + LVGL 的智能健康监测手表，实现心率/血氧监测、六轴计步、蓝牙交互、闹钟与低功耗管理，采用 APP → Middleware → BSP → HAL 四层分层架构，业务代码与硬件完全解耦。

## 功能特性

### 已实现

- **表盘界面**：时间/日期/蓝牙连接状态/健康摘要，应用菜单页（9 宫格）+ 各应用详情页，滑动切换
- **心率/血氧监测**：MAX30102 采集（100sps），移植 Maxim 官方算法，内置手指接触检测（IR 直流阈值）与生理范围过滤，无手指时自动判定无效
- **计步**：ICM20602 六轴姿态解算计步，步数存 RTC 备份寄存器（VBAT 掉电保持），跨日自动清零
- **蓝牙交互**：DX-BT24 SPP 文本指令，手机可设置/查询时间日期、查询心率血氧，非法输入自动回错
- **闹钟**：每日闹钟，响铃全屏弹窗自动亮屏，手动停止或 10 秒自动停铃，开关状态掉电保持
- **低功耗**：20 秒无操作自动熄屏（背光 PWM 关断），CPU 进入 WFI 睡眠，触摸/闹钟中断唤醒；亮屏期间不睡眠保证界面响应
- **可靠性**：软件 I2C 总线死锁自愈（9 时钟脉冲释放从机 + 全量重配置），传感器故障后无限重试且系统不重启、界面与蓝牙不中断

### 规划中

- 抬手唤醒（IMU 手势识别）
- 游戏页、更多表盘
- GPRS（SIM800C）通话/短信、OTA 升级

## 软件架构

### 分层设计

严格单向依赖：APP 只调中间层，中间层只调 BSP，BSP 只调 HAL，HAL 封装全部芯片寄存器操作。更换芯片仅需重写 HAL 层与 `hardware_config.h` 引脚配置，BSP 驱动与全部业务代码零改动。

```text
┌─────────────────────────────────────────────┐
│              应用层 (APP)                     │
│   app_task 任务编排 | app_ui 界面 | app_ble  │
├─────────────────────────────────────────────┤
│           中间件层 (Middleware)               │
│   svc_sys/rtc/health/bt/display 服务封装     │
│   imu_algo 计步算法 | protocol | uart_log    │
├─────────────────────────────────────────────┤
│             板级驱动层 (BSP)                  │
│   st7789 显示 | cst816 触摸 | max30102       │
│   icm20602 六轴 | dx24 蓝牙 | bsp_rtc/beep   │
├─────────────────────────────────────────────┤
│           硬件抽象层 (HAL)                    │
│   hal_gpio/uart/spi/tim/led/rtc/delay       │
│   hardware_config.h 引脚配置中心             │
├─────────────────────────────────────────────┤
│           标准库 (FWLIB) + 内核 (CORE)       │
└─────────────────────────────────────────────┘
```

### 任务划分

| 任务 | 优先级 | 栈(字) | 职责 |
| ---- | ------ | ------ | ---- |
| app_task | 4 | 512 | 硬件初始化、创建子任务、心跳 LED |
| user_task | 4 | 2048 | LVGL 渲染/输入处理/界面刷新（5ms 周期） |
| max30102 | 4 | 512 | 心率血氧采集与计算（100ms 轮询 FIFO） |
| dx24 | 2 | 512 | 蓝牙收发与文本指令解析（空闲中断+任务通知） |
| icm20602 | 1 | 512 | 六轴采样与计步（50ms 周期） |

LVGL 非线程安全：传感器数据经共享变量传递，界面刷新全部收敛在 user_task 内完成。

## 硬件介绍

| 硬件模块 | 型号 | 接口 | 用途 |
| -------- | ---- | ---- | ---- |
| 主控芯片 | STM32F407ZET6 | — | 512KB Flash / 192KB RAM，运行 FreeRTOS |
| 显示屏 | P169H002-CTI（ST7789，240×300） | SPI1（PB3/PB5），TIM2_CH3 PWM 背光（PA2） | 界面显示 |
| 触摸屏 | CST816 | 软件 I2C（PB8=SCL，PB9=SDA） | 触摸交互 |
| 蓝牙模块 | DX-BT24 | USART6（PC6-TX/PC7-RX），STATE（PB6） | 手机通信 |
| 心率血氧传感器 | MAX30102 | 软件 I2C（PC8=SDA，PC9=SCL） | 心率/血氧采集 |
| 六轴传感器 | ICM20602 | 软件 I2C（PB0=SCL，PC13=SDA） | 计步 |
| 实时时钟 | 片内 RTC + LSE 32.768kHz | VBAT 备份域 | 走时/闹钟/步数掉电保持 |
| 其他 | 蜂鸣器（PF8）、LED×2（PF9/PF10）、调试串口 USART1（PA9/PA10，9600） | — | 闹钟响铃/指示/日志 |

## 蓝牙指令

连接后发送文本指令（大小写不敏感，自动去除 `\r\n`）：

| 指令 | 功能 | 应答示例 |
| ---- | ---- | -------- |
| `GetHR` | 查询心率 | `HR:72` |
| `GetSpO2` | 查询血氧 | `SpO2:98` |
| `GetDate` | 查询日期 | `Date:2026.9.1` |
| `GetTime` | 查询时间 | `Time:16.41.00` |
| `SetDate2026.9.1` | 设置日期（兼容 2/4 位年） | `Date:2026.9.1`，非法输入回 `Date:ERR` |
| `SetTime16.41.00` | 设置时间 | `Time:16.41.00`，非法输入回 `Time:ERR` |

设置成功后界面自动同步刷新。

## 目录结构

```text
Health_Monitoring_Watch/
├── USER/               # Keil 工程（Template.uvprojx）+ main.c/中断/时钟配置
├── APP/                # 应用层：任务编排(app_task)、界面(app_ui)、蓝牙指令(app_ble)
├── Middleware/         # 中间件层：svc_* 服务封装、imu_algo 计步、协议、日志
├── BSP/                # 板级驱动层：显示屏/触摸/传感器/蓝牙/RTC/蜂鸣器等
├── HAL/                # 硬件抽象层：hal_* 通用外设驱动 + hardware_config.h 配置中心
├── Common/             # 通用算法（Maxim 心率血氧算法）
├── LVGL/               # LVGL 图形库（examples/porting 为移植层）
├── FreeRTOS/           # FreeRTOS 内核（CM4F 移植层 + heap_4）
├── CORE/               # 启动文件与 Cortex-M4 内核头文件
└── FWLIB/              # STM32F4 标准外设库（StdPeriph）
```

## 快速开始

### 开发环境

- Keil MDK 5（ARMCC）
- J-Link / ST-Link 下载器
- 蓝牙串口 APP（如"蓝牙串口"）或串口助手

### 编译烧录

1. Keil 打开 `USER/Template.uvprojx`，直接编译（0 错误）
2. 烧录固件，USART1@9600 查看运行日志
3. 手机连接蓝牙 `DX-BT24`，发送 `GetTime` 等指令验证
